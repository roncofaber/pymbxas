# Historical design records

The files in this directory are implementation-time specifications, plans, and
reviews retained for provenance. Some were written for a particular agent
workflow and may mention tools or process conventions that are not available
to every contributor.

They are not active repository instructions. Current contributors and coding
agents should follow `AGENTS.md`, `dev/method.md`, `dev/shakeup.md`, and
`dev/architecture.md`. Where a historical record conflicts with those files or
with the code and tests, the maintained `dev/` documentation and current code
take precedence.
